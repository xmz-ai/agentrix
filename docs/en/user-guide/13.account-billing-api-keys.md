# Account, Billing, and API Keys

Use **Settings** to manage your account, execution machines, billing state, API keys, and app preferences.

## Account

The account section includes profile, subscription, credits, and connected OAuth accounts.

### Profile

In **Settings** -> **Profile**, you can update:

- Avatar
- Username
- Email address

Usernames and email addresses must be unique. If another account already uses the value, the app shows a validation error.

### OAuth Accounts

Connected OAuth accounts let Agentrix access providers such as GitHub or GitLab on your behalf. Repository mode uses these connections to list repositories, issues, and merge requests.

If repository access fails, return to Settings and confirm the expected OAuth account is connected.

## Subscription

Open **Settings** -> **Subscription** to view your current plan and available plans. When billing is configured for the deployment, this screen can:

- Show the current plan, renewal or expiry date, monthly price, and included credits.
- Open the customer portal to manage an active subscription.
- Start checkout for a new plan.
- Show plan features and highlight the popular plan when configured.

If the screen says subscription features are not configured, the deployment administrator has not enabled billing for that environment.

## Credits

Open **Settings** -> **Credits** to see account balance, active credit packages, and transaction history.

The credits screen shows:

- Total current balance.
- Active credit buckets and expiry dates.
- Recharge options when credit packages are available.
- Transaction history for recharge and usage events.

Refresh the screen if a recent payment or usage event has not appeared yet. The app also listens for billing updates over WebSocket while the credits screen is open.

## Devices

### Local Machines

Open **Settings** -> **Local Machines** to see machines bound to your account. The list shows online status, host information, platform, and CLI version where available.

You can unbind a local machine from this screen. Unbinding removes the machine's association with your account. The next `agentrix start` on that machine needs authentication again.

### Private Clouds

Open **Settings** -> **Private Clouds** to create and manage team runner pools. Private Clouds are covered in detail in [Private Cloud Setup](9.private-cloud.md).

## Preferences

The preferences section lets you adjust:

- Layout
- Theme and appearance
- Language

These preferences affect the app UI only. They do not change daemon behavior.

## Privacy

Open **Settings** -> **Privacy** to view, copy, or change the local account entry password used by the app's encryption and restore flows.

Treat this password as sensitive. Anyone with the password and the required account context may be able to restore protected data.

## API Keys

API keys are used by automation such as `agentrix-run`, GitHub Actions, GitLab CI, and custom scripts.

Open **Settings** -> **API Keys** to:

- Create a key with a name.
- Copy the key once from the reveal modal.
- See the key prefix, last-used time, expiry, and enabled state.
- Delete keys you no longer use.

Store API keys in a secret manager or CI secret store. Agentrix only shows the full key immediately after creation.

## Safe API Key Rotation

1. Create a new key with a clear name, for example `github-actions-agentrix`.
2. Update the CI secret or automation environment.
3. Run the automation once and confirm the new key works.
4. Delete the old key from **Settings** -> **API Keys**.

For `agentrix-run`, set the key through `AGENTRIX_API_KEY` or the GitHub Action `api-key` input. See [agentrix-run](8.agentrix-run.md) for CI examples.
