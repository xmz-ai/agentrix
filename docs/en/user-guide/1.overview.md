# User Guide

Welcome to the Agentrix User Guide. This documentation covers everything you need to use the
Agentrix platform as an end user.

## What is Agentrix?

Agentrix is an enterprise AI agent hosting and collaboration platform. It lets your team dispatch
coding and analysis tasks to AI agents that run on your own machines, keeping source code and data
under your control.

### Core concepts

| Concept | Description |
|---|---|
| **Task** | A unit of work sent from the web app or API to an agent |
| **Daemon** | A long-running background process that manages workers on your machine |
| **Worker** | A child process spawned by the daemon for each task (Claude, Codex, or other agent types) |
| **Machine** | A registered local environment bound to your Agentrix account |
| **Workspace** | An isolated directory where a worker runs each task |

### How it works

```
Web App / API
      │ WebSocket
      ▼
  Agentrix Backend
      │ WebSocket (machine channel)
      ▼
  Daemon  ──────── ~/.agentrix/logs/daemon.log
      │ spawn
      ▼
  Worker process  ──── ~/.agentrix/logs/worker-<taskId>.log
      │ git worktree / isolated workspace
      ▼
  Task result → synced back to backend
```

1. You create a task in the web app, linking it to a repository and selecting an agent type.
2. The backend sends the task over a WebSocket connection to the daemon running on your machine.
3. The daemon spawns a worker in an isolated workspace.
4. The worker (e.g. Claude Code) processes the task, commits results, and syncs them back.

## Choose Your Setup Path

How you install Agentrix depends on your operating system and use case.

### Desktop App — macOS or Windows

The Desktop app is the recommended way for developers on **macOS or Windows**. It is a
self-contained Electron application that:

- Installs and manages its own Node.js runtime (no pre-installed Node.js required)
- Guides you through installing all dependencies (Git, Claude CLI, ripgrep, etc.) via a UI
- Manages the daemon through a **system tray icon**
- Embeds the Agentrix web app directly in the window
- Handles authentication via a native deep-link callback

**→ [Desktop App Setup (macOS / Windows)](2.desktop-setup.md)**

---

### CLI — Linux, servers, or CI/CD

The CLI is the right choice for **Linux machines, headless servers, and automated pipelines**.
It requires Node.js 18+ and manual installation of dependencies.

```bash
npm install -g @agentrix/cli
agentrix start
```

**→ [CLI Setup (Linux / Server)](3.cli-setup.md)**

## Directory Layout

Both the Desktop app and CLI store state under the same directory:

```
~/.agentrix/
├── credentials.json      — machine token (do not share)
├── settings.json         — daemon and sandbox configuration
├── daemon.state.json     — running daemon metadata (PID, port, version)
├── workspaces/           — per-task isolated working directories
├── agents/               — installed custom agents
├── config/
│   ├── claude/           — Claude Code config scoped to Agentrix
│   └── codex/            — Codex config scoped to Agentrix
└── logs/
    ├── daemon.log
    └── worker-<taskId>.log
```

Override the root directory with the `AGENTRIX_HOME_DIR` environment variable.
