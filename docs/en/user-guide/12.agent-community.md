# Agent Community

Agent Community is the in-app marketplace for agents and skills. Open **Explore** from the sidebar to discover published listings, install them to a local machine, publish your own work, and discuss listings with other users.

## Marketplace

The **Market** tab lists published agents and skills. You can:

- Search by name, display name, or description.
- Filter by type: all, agent, or skill.
- Sort by trending, newest, rating, or installs.
- Open a listing to see author, version, category, tags, description, install count, rating, reviews, and discussion.

## Install a Listing

Listings install onto online local machines.

1. Open **Explore** -> **Market**.
2. Open an agent or skill listing.
3. Select an online local machine.
4. Click **Install**.

The app blocks duplicate installs on the same selected machine. If another install is already running, the listing shows an install-in-progress message.

Installed agents and skills use the selected machine because installation writes into that machine's Agentrix agent or skill directories.

## Reviews

Open a listing and switch to **Reviews** to read feedback. You can write or update your own review with a rating and optional comment. Reviews help other users decide whether a listing is maintained and useful for their workflow.

## Discussions

Open **Discussion** on a listing to start a thread, reply to existing comments, edit your comments, or delete your comments. Discussion threads are useful for setup questions, usage notes, and release feedback that should stay attached to the listing.

## My Agents

The **My Agents** tab shows two groups:

- **Published** listings that belong to you.
- **Drafts** that exist in your account but have not been published.

Draft agents can be published from this tab. Published listings can be opened from the same list to review metadata, update the published version, and read feedback.

## Publish an Agent

Agent publishing starts from a draft agent created by the app or by an agent workflow.

1. Open **Explore** -> **My Agents**.
2. Find the draft.
3. Click **Publish**.
4. Fill in name, display name, description, category, and tags.
5. Submit the publish request.

The source task for the draft determines the machine used for publishing. If the app cannot determine that machine, it asks you to fix the draft context before publishing.

## Publish a Skill

Skills publish from a directory on an online local machine.

1. Open **Explore** -> **Publish Skill**.
2. Select an online local machine.
3. Enter the skill directory path.
4. Submit the publish request.

The directory must contain `SKILL.md`. Agentrix reads the skill name and description from the file's frontmatter.

## Update a Published Version

If you authored a listing, open its detail page and use the update action.

- Agent listings update from the machine associated with the original draft source task.
- Skill listings update from the selected online local machine and the source directory you provide.

After the update finishes, the listing shows the new version metadata.

## When to Use Community Listings

Use community agents for repeatable workflows that need a dedicated persona, prompt, or configuration. Use skills when you want to add a reusable capability to an agent, such as a specific tool workflow, API procedure, or domain guide.

Review listing details before installing, especially when a skill will give an agent access to local tools or credentials through your machine.
