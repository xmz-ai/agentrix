# CLI Command Reference

## Global Options

| Flag | Description |
|---|---|
| `--version`, `-v` | Print the CLI version |
| `--help`, `-h` | Show help for any command |
| `--debug`, `-d` | Use local-debug mode (plaintext output, for debugging) |

---

## agentrix start

Start the daemon if it is not already running, then show its status.

```bash
agentrix start
```

**What it does:**

1. Authenticates (browser OAuth on first run, or validates existing credentials).
2. Checks critical dependencies (git, sandbox tools). Exits if any are missing.
3. Spawns the daemon as a detached background process.
4. Waits up to 5 seconds for the daemon to report ready.
5. Starts the upgrade-daemon if auto-upgrade is enabled.
6. Prints daemon status.

**Example:**

```
Starting Agentrix background service...
✓ Daemon started successfully

🤖 Daemon Status
✓ Daemon is running
  PID: 12345
  Started: 4/22/2026, 10:00:00 AM
  CLI Version: 1.2.3
  HTTP Port: 51234
```

**Related env vars:**

| Variable | Effect |
|---|---|
| `AGENTRIX_DISABLE_AUTO_UPGRADE=true` | Skip auto-upgrade check |

## agentrix stop

Stop the running daemon.

```bash
agentrix stop
```

Any active worker sessions are terminated when the daemon stops.

---

## agentrix status

Show daemon and authentication status.

```bash
agentrix status
```

This is equivalent to running `agentrix doctor` filtered to daemon + auth sections.

**Example output:**

```
🤖 Daemon Status
✓ Daemon is running
  PID: 12345
  Started: 4/22/2026, 10:00:00 AM
  CLI Version: 1.2.3
  HTTP Port: 51234

🔐 Authentication
✓ Authenticated (credentials found)
```

## agentrix doctor

Full system diagnostics — version, configuration, environment variables, authentication,
dependencies, and daemon status.

```bash
agentrix doctor
```

Use this as the first step when troubleshooting. It shows:

- CLI version, platform, Node.js version
- Daemon spawn paths (wrapper script, entrypoint)
- Configuration (home dir, server URL, log dir)
- Environment variables that affect Agentrix behavior
- Authentication status
- Dependency status (git, claude, codex, sandbox tools)
- Daemon status (running / stale / not running)

## agentrix upgrade

Upgrade the CLI to the latest version on npm.

```bash
agentrix upgrade
```

This runs `npm install -g @agentrix/cli@latest` and:

- Also checks for agent updates (companion, etc.).
- Restarts the daemon automatically if it was running.

The CLI also upgrades itself automatically on each `agentrix start` (unless
`AGENTRIX_DISABLE_AUTO_UPGRADE=true`).

## agentrix logout

Unbind this machine from your Agentrix account.

```bash
agentrix logout
```

Removes `~/.agentrix/credentials.json`. The next `agentrix start` will open the browser
authentication flow again.

---

## agentrix ls

List sessions currently tracked by the running daemon.

```bash
agentrix ls
```

Each session corresponds to a running or recently-started worker process.

**Example:**

```
Active sessions:
[
  {
    "taskId": "task-abc123",
    "pid": 54321,
    "startedBy": "cli"
  }
]
```

Returns `No active sessions` if no workers are running.

---

## agentrix kill \<sessionId\>

Stop a specific worker session by its task ID.

```bash
agentrix kill task-abc123
```

---

## agentrix killall

Terminate all runaway agentrix processes found on the system.

```bash
agentrix killall
```

Use this when sessions are stuck or the daemon state is inconsistent. Reports how many processes
were killed.

## Environment Variables

These variables modify CLI behavior without changing `settings.json`.

| Variable | Default | Description |
|---|---|---|
| `AGENTRIX_HOME_DIR` | `~/.agentrix` | Root state directory |
| `AGENTRIX_SERVER_URL` | `https://agentrix.xmz.ai` | Backend API URL |
| `AGENTRIX_WEBAPP_URL` | `https://agentrix.xmz.ai` | Web app URL (used for auth redirect) |
| `AGENTRIX_WORKSPACE_HOME_DIR` | `~/.agentrix/workspaces` | Task workspace root |
| `AGENTRIX_AGENTS_HOME_DIR` | `~/.agentrix/agents` | Custom agent install root |
| `AGENTRIX_CLAUDE_HOME` | `~/.agentrix/config/claude` | Claude Code config dir |
| `AGENTRIX_CODEX_HOME` | `~/.agentrix/config/codex` | Codex config dir |
| `AGENTRIX_DISABLE_AUTO_UPGRADE` | — | Set to `true` to disable automatic upgrades |
| `AGENTRIX_DISABLE_CAFFEINATE` | — | Set to `true` to allow the machine to sleep during tasks |
| `CLOUD_AUTH_TOKEN` | — | Token injected by the Agentrix platform for cloud-hosted machines; not for manual use |
| `DEBUG` | — | Enable verbose debug logging |
