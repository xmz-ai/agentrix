# 账户、计费与 API Keys

在 **Settings** 中管理账户、执行机器、计费状态、API keys 和应用偏好。

## Account

Account 区域包含 profile、subscription、credits 和已连接的 OAuth accounts。

### Profile

在 **Settings** -> **Profile** 中可以更新：

- 头像
- 用户名
- 邮箱地址

用户名和邮箱必须唯一。如果另一个账户已经使用该值，应用会显示校验错误。

### OAuth Accounts

连接 OAuth accounts 后，Agentrix 才能代表你访问 GitHub 或 GitLab 等 providers。Repository mode 会使用这些连接列出仓库、issues 和 MRs。

如果仓库访问失败，回到 Settings 确认对应 OAuth account 是否已连接。

## Subscription

打开 **Settings** -> **Subscription** 可以查看当前 plan 和可用 plans。当部署启用了 billing 后，该页面可以：

- 显示当前 plan、续费或到期日期、月费和包含的 credits。
- 打开 customer portal 管理现有订阅。
- 为新 plan 启动 checkout。
- 显示 plan features，并在配置后标记 popular plan。

如果页面显示 subscription features are not configured，说明当前部署环境的管理员没有启用 billing。

## Credits

打开 **Settings** -> **Credits** 可以查看账户余额、有效 credit packages 和交易历史。

Credits 页面会显示：

- 当前总余额。
- 有效 credit buckets 和过期时间。
- 可用时显示充值入口。
- Recharge 和 usage 交易历史。

如果最近的支付或用量记录还没出现，可以刷新页面。Credits 页面打开时，应用也会通过 WebSocket 监听 billing 更新。

## Devices

### Local Machines

打开 **Settings** -> **Local Machines** 可以查看绑定到账户的机器。列表会显示在线状态、host 信息、平台和 CLI 版本。

你可以在这里 unbind local machine。解绑会移除这台机器与账户的关联；下一次在该机器上运行 `agentrix start` 时，需要重新认证。

### Private Clouds

打开 **Settings** -> **Private Clouds** 可以创建和管理团队 runner pool。Private Clouds 的完整说明见 [Private Cloud 部署](9.private-cloud.md)。

## Preferences

Preferences 区域可以调整：

- Layout
- Theme 和 appearance
- Language

这些偏好只影响应用 UI，不会改变 daemon 行为。

## Privacy

打开 **Settings** -> **Privacy** 可以查看、复制或修改本地账户 entry password。应用的加密和恢复流程会用到它。

请把这个 password 当作敏感信息处理。拥有该 password 和必要账户上下文的人，可能恢复受保护的数据。

## API Keys

API keys 用于 `agentrix-run`、GitHub Actions、GitLab CI 和自定义脚本等自动化场景。

打开 **Settings** -> **API Keys** 可以：

- 用名称创建 key。
- 在 reveal modal 中一次性复制完整 key。
- 查看 key prefix、last-used time、expiry 和 enabled 状态。
- 删除不再使用的 keys。

请把 API keys 存到 secret manager 或 CI secret store。Agentrix 只会在创建后立即显示完整 key。

Authorization: Bearer YOUR_API_KEY

## 安全轮换 API Key

1. 创建一个命名清楚的新 key，比如 `github-actions-agentrix`。
2. 更新 CI secret 或自动化环境变量。
3. 运行一次自动化任务，确认新 key 可用。
4. 从 **Settings** -> **API Keys** 删除旧 key。

`agentrix-run` 可以通过 `AGENTRIX_API_KEY` 或 GitHub Action 的 `api-key` input 传入 key。CI 示例见 [agentrix-run](8.agentrix-run.md)。
