# 桌面应用安装（macOS / Windows）

Agentrix 桌面应用是在 macOS 和 Windows 上使用 Agentrix 的推荐方式。它是一个开箱即用的
应用程序——无需预先安装 Node.js 或包管理器。

## 下载

从 [agentrix.xmz.ai](https://agentrix.xmz.ai) 下载安装包：

- **macOS** — `.dmg` 文件（支持 Apple Silicon 和 Intel）
- **Windows** — `.exe` 安装程序

### macOS 安装

1. 打开 `.dmg` 文件。
2. 将 **Agentrix** 拖入 **Applications（应用程序）** 文件夹。
3. 从 Applications 或 Spotlight 启动 **Agentrix**。

> 首次启动时 macOS 可能显示安全提示。前往**系统设置 → 隐私与安全性**，点击**仍要打开**。

### Windows 安装

1. 运行 `.exe` 安装程序。
2. 按照安装向导操作。
3. 安装完成后 Agentrix 会自动启动。

---

## 首次启动

首次启动时，应用会打开**依赖安装**界面，自动检查并安装每个必要工具。

### macOS 依赖项

| 工具 | 安装方式 |
|---|---|
| Homebrew | 官方安装脚本 |
| Node.js | 托管运行时（下载至 `~/.agentrix/node-runtime/`） |
| Git | `brew install git` |
| ripgrep | `brew install ripgrep` |
| Claude CLI | `brew install --cask claude-code` |
| Codex CLI | `npm install -g @openai/codex` |
| Agentrix CLI | `npm install -g @agentrix/cli` |

### Windows 依赖项

| 工具 | 安装方式 |
|---|---|
| Scoop | 官方 PowerShell 安装脚本 |
| Node.js | 托管运行时（下载至 `%USERPROFILE%\.agentrix\node-runtime\`） |
| Git | `scoop install git` |
| Claude CLI | `npm install -g @anthropic-ai/claude-code` |
| Codex CLI | `npm install -g @openai/codex` |
| Agentrix CLI | `npm install -g @agentrix/cli` |

应用会实时显示每个步骤的输出，如有失败可以重试。您无需手动执行任何命令。

---

## 认证

依赖安装完成后，应用会在浏览器中打开 Agentrix 登录页面。登录账户后，应用通过深链接回调
（`agentrix-desktop://`）自动接收认证令牌。

令牌存储在 `~/.agentrix/credentials.json` 中，与 CLI 守护进程共用。

---

## 系统托盘

设置完成后，Agentrix 以**系统托盘图标**运行（macOS 菜单栏 / Windows 通知区域）。

托盘图标一目了然地显示守护进程状态：

| 图标状态 | 含义 |
|---|---|
| ● 运行中 | 守护进程正在运行并接受任务 |
| ◐ 启动中 | 守护进程正在启动 |
| ○ 已停止 | 守护进程未运行 |

**右键单击托盘图标**打开上下文菜单：

- **Show Dashboard（打开面板）** — 打开主应用窗口
- **Open Web App（打开 Web 应用）** — 在浏览器中打开 [agentrix.xmz.ai](https://agentrix.xmz.ai)
- **Daemon → Start / Stop / Restart（守护进程 → 启动 / 停止 / 重启）** — 控制守护进程
- **Quit（退出）** — 退出桌面应用（守护进程同时停止）

---

## 应用窗口

点击托盘图标（或选择 **Show Dashboard**）打开主窗口。窗口内嵌了 Agentrix Web 应用，
您无需离开桌面应用即可访问任务、设置和团队功能。

---

## 配置

桌面应用与 CLI 读写同一个 `~/.agentrix/settings.json`。您可以直接编辑该文件，也可以
在应用内的 Settings 界面中修改。

完整配置说明请参见[配置](6.settings.md)。

---

## 更新

桌面应用在启动时检查更新。有新版本可用时会提示您更新。

应用内的 Agentrix CLI 组件（`@agentrix/cli`）也会通过依赖管理器单独更新。

---

## 卸载

### macOS

1. 从托盘菜单退出应用。
2. 将 **Agentrix.app** 从 Applications 拖入废纸篓。
3. 可选：删除状态数据：

```bash
rm -rf ~/.agentrix
```

### Windows

1. 从托盘菜单退出应用。
2. 通过**设置 → 应用 → Agentrix** 卸载。
3. 可选：删除 `%USERPROFILE%\.agentrix` 中的状态数据。
