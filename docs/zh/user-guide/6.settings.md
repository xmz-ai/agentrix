# 配置

CLI 读写 `~/.agentrix/settings.json`。该文件在首次运行时以默认值创建，可手动编辑。

## 完整 Schema

```json
{
  "sandbox": {
    "enabled": false,
    "network": {
      "allowedDomains": "*",
      "deniedDomains": []
    },
    "filesystem": {
      "allowWrite": ["..."],
      "denyRead": [],
      "denyWrite": []
    }
  },
  "daemonEnv": {
    "enabled": false,
    "variables": {}
  },
  "allowDirectBash": true
}
```

---

## sandbox

控制 Worker 进程的文件系统和网络隔离。

### sandbox.enabled

```json
{ "sandbox": { "enabled": false } }
```

- `false`（默认）— 禁用沙箱；Worker 以您的普通用户权限运行。
- `true` — Worker 在隔离环境中运行（macOS：文件系统限制；Linux：bubblewrap 命名空间）。

### sandbox.network

```json
{
  "sandbox": {
    "network": {
      "allowedDomains": "*",
      "deniedDomains": []
    }
  }
}
```

- `allowedDomains` — `"*"`（允许所有）或允许的域名模式列表。
- `deniedDomains` — 即使 `allowedDomains` 为 `"*"` 也要屏蔽的域名模式列表。

### sandbox.filesystem

控制沙箱化 Worker 的读写权限。

**macOS**（仅拒绝模式）：

```json
{
  "sandbox": {
    "filesystem": {
      "denyRead": [],
      "allowWrite": ["~/.agentrix/config/claude", "~/.agentrix/config/codex"],
      "denyWrite": []
    }
  }
}
```

**Linux**（仅允许模式）：

```json
{
  "sandbox": {
    "filesystem": {
      "allowRead": ["~/.agentrix"],
      "autoAllowSystemPaths": true,
      "allowWrite": ["~/.agentrix/config/claude", "~/.agentrix/config/codex"],
      "denyWrite": []
    }
  }
}
```

> Agentrix 默认会在 `allowWrite` 中预填充 Worker 所需的路径（代理配置目录等）。
> 启用沙箱时，请根据需要添加您自己的路径。

## daemonEnv

在守护进程和 Worker 进程启动时注入环境变量。适用于企业代理、自定义工具路径或其他需要被代理继承的配置。

### daemonEnv.enabled

```json
{ "daemonEnv": { "enabled": false } }
```

- `false`（默认）— 不注入自定义变量（始终生效的 key 除外，见下文）。
- `true` — 注入 `daemonEnv.variables` 中的所有条目。

### daemonEnv.variables

```json
{
  "daemonEnv": {
    "enabled": true,
    "variables": {
      "HTTP_PROXY": "http://proxy.corp.example.com:8080",
      "HTTPS_PROXY": "http://proxy.corp.example.com:8080",
      "NO_PROXY": "localhost,127.0.0.1,.corp.example.com"
    }
  }
}
```

**代理别名** — 设置以下任意 key 时，会自动同时设置大写和小写变体：

- `HTTP_PROXY` / `http_proxy`
- `HTTPS_PROXY` / `https_proxy`
- `NO_PROXY` / `no_proxy`
- `ALL_PROXY` / `all_proxy`
- `GLOBAL_AGENT_HTTP_PROXY` / `global_agent_http_proxy`

**始终生效的 key** — 以下 key 即使在 `daemonEnv.enabled` 为 `false` 时也会生效，
让您无需开启全量注入即可为代理指定自定义配置目录：

| Key | 作用 |
|---|---|
| `AGENTRIX_CLAUDE_HOME` | 为 Claude Worker 设置 `CLAUDE_CONFIG_DIR` |
| `AGENTRIX_CODEX_HOME` | 为 Codex Worker 设置 `CODEX_HOME` |
| `AGENTRIX_CLAUDE_PATH` | 覆盖 `claude` 二进制文件路径 |
| `AGENTRIX_CODEX_PATH` | 覆盖 `codex` 二进制文件路径 |

**示例 — 使用自定义 Claude 配置目录：**

```json
{
  "daemonEnv": {
    "enabled": false,
    "variables": {
      "AGENTRIX_CLAUDE_HOME": "~/.my-team-claude-config"
    }
  }
}
```

## allowDirectBash

```json
{ "allowDirectBash": true }
```

- `true`（默认）— Worker 可以直接执行 bash 命令。
- `false` — 限制直接 bash 执行（启用沙箱时此设置才有实际意义）。

---

## 应用更改

设置在守护进程启动时读取。编辑 `settings.json` 后，重启守护进程：

```bash
agentrix stop
agentrix start
```
