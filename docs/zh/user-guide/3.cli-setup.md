# CLI 安装（Linux / 服务器 / CI）

在 **Linux 机器、无头服务器或 CI/CD 流水线**上运行 Agentrix 时请使用 CLI。

> **macOS 或 Windows 桌面用户？** 请改用[桌面应用](2.desktop-setup.md)——它会自动完成所有安装步骤。

## 前提条件

| 要求 | 说明 |
|---|---|
| **Node.js 18+** | 安装和运行 CLI 所必须 |
| **npm** | 用于全局安装 CLI |
| **Git** | 所有任务都依赖 Git |
| **Claude Code CLI** | Claude 代理任务所必须，详见[依赖项](4.dependencies.md) |
| **Agentrix 账户** | 在 [agentrix.xmz.ai](https://agentrix.xmz.ai) 注册 |

## 安装

```bash
npm install -g @agentrix/cli
```

验证安装：

```bash
agentrix --version
```

然后安装必要的外部工具：

```bash
# 安装 Claude Code CLI（大多数任务需要）
npm install -g @anthropic-ai/claude-code

# Linux 沙箱依赖
sudo apt install bubblewrap socat   # Debian / Ubuntu
```

所有平台的详细信息和备选方案请参见[依赖项](4.dependencies.md)。

## 认证

首次运行时，`agentrix start` 需要将此机器绑定到您的账户。

```bash
agentrix start
```

CLI 会：

1. 生成唯一的机器 ID。
2. 打印 URL 并尝试在默认浏览器中打开。
3. 等待您在浏览器中完成 OAuth 流程。
4. 将令牌保存到 `~/.agentrix/credentials.json` 并启动守护进程。

```
Web Authentication

Opening your browser...
✓ Browser opened

Complete authentication in your browser window.

If the browser did not open, please copy and paste this URL:
https://agentrix.xmz.ai/auth/machine?...

Waiting for authentication...
```

如果浏览器未自动打开，请将 URL 复制到任意已登录 Agentrix 账户的浏览器中打开。

## 查看状态

```bash
agentrix status
```

显示守护进程状态（PID、端口、CLI 版本）和认证状态。

```
🤖 Daemon Status
✓ Daemon is running
  PID: 12345
  CLI Version: 1.2.3
  HTTP Port: 51234

🔐 Authentication
✓ Authenticated (credentials found)
```

## 退出登录

```bash
agentrix logout
```

删除 `~/.agentrix/credentials.json`。下次运行 `agentrix start` 时将重新触发认证流程。

## 状态目录

| 路径 | 用途 |
|---|---|
| `~/.agentrix/credentials.json` | 机器令牌 — 请保密 |
| `~/.agentrix/credentials/` | 私有 GitLab PAT、webhook secret、pipeline trigger token 等加密凭据 |
| `~/.agentrix/settings.json` | 守护进程与沙箱配置 |
| `~/.agentrix/daemon.state.json` | 运行中的守护进程元数据 |
| `~/.agentrix/workspaces/` | 每个任务的隔离工作目录 |
| `~/.agentrix/agents/` | 已安装的自定义代理 |
| `~/.agentrix/config/claude/` | Agentrix 专用的 Claude Code 配置 |
| `~/.agentrix/config/codex/` | Agentrix 专用的 Codex 配置 |
| `~/.agentrix/config/gemini/` | Agentrix 专用的 Gemini 配置 |
| `~/.agentrix/logs/daemon.log` | 守护进程日志文件 |
| `~/.agentrix/logs/worker-<taskId>.log` | 每个任务的 Worker 日志 |

通过 `AGENTRIX_HOME_DIR` 覆盖根目录：

```bash
export AGENTRIX_HOME_DIR=/opt/agentrix
agentrix start
```

## 升级

```bash
agentrix upgrade
```

执行 `npm install -g @agentrix/cli@latest`，如果守护进程正在运行则自动重启。

`agentrix start` 不会自动检查升级；需要更新 CLI 时，请手动运行 `agentrix upgrade`。
