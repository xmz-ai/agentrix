# Agent Community

Agent Community 是应用内的 agents 与 skills marketplace。从侧边栏打开 **Explore**，可以发现已发布 listing、安装到本地机器、发布自己的内容，并围绕 listing 评价和讨论。

## Marketplace

**Market** 标签页展示已发布的 agents 和 skills。你可以：

- 按 name、display name 或 description 搜索。
- 按类型过滤：all、agent、skill。
- 按 trending、newest、rating 或 installs 排序。
- 打开 listing 查看作者、版本、分类、tags、描述、安装量、评分、reviews 和 discussion。

## 安装 Listing

Listing 会安装到在线的本地机器上。

1. 打开 **Explore** -> **Market**。
2. 打开一个 agent 或 skill listing。
3. 选择在线 local machine。
4. 点击 **Install**。

应用会阻止在同一台机器上重复安装同一个 listing。如果另一个安装任务正在进行，页面会显示 install-in-progress 提示。

安装目标是选中的本地机器，因为安装过程会写入该机器上的 Agentrix agent 或 skill 目录。

## Reviews

打开 listing 后切到 **Reviews**，可以查看反馈。你也可以写入或更新自己的 review，包括评分和可选评论。Reviews 帮助其他用户判断 listing 是否维护良好、是否适合自己的工作流。

## Discussions

打开 listing 的 **Discussion** 可以发起线程、回复已有评论、编辑自己的评论或删除自己的评论。Discussion 适合保留安装问题、使用经验和版本反馈。

## My Agents

**My Agents** 标签页分成两组：

- **Published**，你已经发布的 listings。
- **Drafts**，账户里存在但尚未发布的 draft agents。

Draft agents 可以从这里发布。已发布 listings 也可以从同一列表打开，用于查看元数据、更新发布版本和阅读反馈。

## 发布 Agent

Agent 发布从 draft agent 开始。Draft agent 通常由应用或 agent 工作流创建。

1. 打开 **Explore** -> **My Agents**。
2. 找到 draft。
3. 点击 **Publish**。
4. 填写 name、display name、description、category 和 tags。
5. 提交发布请求。

Draft 的 source task 决定发布使用的机器。如果应用无法判断机器，会要求你先修复 draft context。

## 发布 Skill

Skill 从在线本地机器上的目录发布。

1. 打开 **Explore** -> **Publish Skill**。
2. 选择在线 local machine。
3. 输入 skill 目录路径。
4. 提交发布请求。

目录中必须包含 `SKILL.md`。Agentrix 会从该文件的 frontmatter 读取 skill name 和 description。

## 更新已发布版本

如果你是 listing 作者，打开详情页并使用 update 操作。

- Agent listing 会从原 draft source task 关联的机器更新。
- Skill listing 会从你选择的在线 local machine 和提供的 source directory 更新。

更新完成后，listing 会显示新的版本元数据。

## 什么时候用 Community Listing

当某个重复工作流需要固定 persona、prompt 或配置时，用 community agent。希望给 agent 增加可复用能力时，用 skill，比如特定工具流程、API 操作步骤或领域指南。

安装前先查看 listing 详情。尤其是 skill 可能通过你的机器让 agent 访问本地工具或凭据，更需要确认来源和用途。
